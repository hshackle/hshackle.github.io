# leynashackleton.github.io

Personal website and academic CV. This project keeps publications, preprints,
talks, posters, and biographical information current using verified public
records and relevant email correspondence.

See [AGENTS.md](AGENTS.md) for maintenance guidelines, evidence handling, CV
synchronization, verification, and publishing preferences.

The editable PDF CV lives in [resume/](resume/README.md); its build instructions
and repair history are recorded there. The public download is
[pdfs/leynaShackletonCV.pdf](pdfs/leynaShackletonCV.pdf). Keep it synchronized
with the website CV in [cv.md](cv.md).

Use the additional local `Presentations` folder added to this project as a
source for talk slides. Its filesystem path is recorded in [AGENTS.md](AGENTS.md).
Publish matched PDF decks under this repository's `presentations/` directory
and link them from the corresponding CV entries.
